## Authentication compatibility correction

Current CLI authentication reads metadata with `org display` and retrieves the in-memory access token with `org auth show-access-token --json`. Neither command output is logged. The bridge uses fixed arguments and never returns credentials through MCP. See [Salesforce documentation](https://developer.salesforce.com/docs/platform/sfdx-dev/guide/sfdx-dev-auth-view-secrets.html). Synthetic transport tests cover the boundary; live JWT verification remains outstanding.
